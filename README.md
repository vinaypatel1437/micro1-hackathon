## 1. The 4 Core Questions (Problem & User Value)

### Q1: Who has this problem?

API platform engineers, backend tech leads, and API security auditors maintaining microservices with many downstream consumers (web/mobile/third-party clients and autogenerated SDKs).

### Q2: What bottleneck makes it worth solving?

Backends change rapidly while OpenAPI specs lag, creating "dark contracts": undocumented runtime behaviors that cause breaking changes, deserialization failures, and silent data corruption. Manually cross-referencing logs against specs is slow and error-prone; single-shot LLM prompts hallucinate on noisy/invalid traffic.

### Q3: Does the agent solve it well?

Yes. `DarkContract-Sentinel` combines deterministic preprocessing (filtering/clustering) with structured LLM reasoning to detect, categorize, and remediate schema drift while minimizing false positives.

### Q4: Can another person reproduce the result?

Yes — run `python generate_dataset.py` then `python evaluate.py` in a clean environment to run the 10-case benchmark.

## 2. Agent Architecture & Engineering

High level flow:

- Declared OpenAPI spec (`openapi.yaml`) and production traffic (`traffic.jsonl`) are inputs.
- A deterministic preprocessing tool clusters payloads and filters noisy 400 responses.
- The clustered signatures are compared to the spec using a structured LLM verifier (Gemini-style reasoning).
- Full execution trajectories are exported to `trajectories/` in JSON and Markdown.

## 5. Improvement Changelog

High-level iterations and outcomes:

1. Baseline: single-shot LLM on raw logs — 40% accuracy.
2. Added deterministic clustering — 80%.
3. Removed multi-agent debate (costly) — kept clustering and filters — 90%.
4. Added polymorphic detection rules — 100%.

## 6. Failure Mode & Practical Hot Take

- Failure: LLMs can treat noisy 400 responses as ground truth and hallucinate spec changes.
- Hot take: Deterministic preprocessing + focused LLM prompts outperform multi-agent debate loops for precision tasks.

## 7. Complete Clean Reproduction Guide

Prereqs: Python 3.10+, a Gemini API key (optional for offline deterministic runs).

Commands (copy/paste):

```bash
git clone https://github.com/vinaypatel1437/micro1-hackathon.git
cd micro1-hackathon
python -m venv venv
# On Windows (PowerShell)
.\venv\Scripts\Activate.ps1
# On Linux/macOS
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# add GEMINI_API_KEY to .env if you want live LLM runs
python generate_dataset.py
python evaluate.py
```
